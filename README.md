# Моделирование A/B - тестирования на данных мобильной игры Cookie Cats

Cookie Cats - мобильная игра free-to-play, данные о пользовательском поведении взяты с Kaggle https://www.kaggle.com/datasets/mursideyarkin/mobile-games-ab-testing-cookie-cats

Источник утверждает, что это
оригинальные данные после создания двух рандомных выборок из клиентов игры. Выборки были сформированы версиями: одним пользователям предлагался первый boss level на уровне 30, а другой группе - на уровне 40.

Эти выборки выступают группами для тестирования в данном
исследовании. Выборки уже были сформированы создателями датасета,
поэтому в данной работе рассматривается только построение решающей
статистики и тестирование метрик.

## Метрики

В этой работе анализируются ключевые метрики для игр F2P (free-to-play), соотносящиеся с особой бизнес-моделью таких игровых продуктов: вовлеченность и удержание. Метрика вовлеченности тестируется с помощью теста Манна-Уитни. Метрики возвращаемости тестируются критерием Хи-квадрат. Также в работе используется моделирование бутстреп-распределения для проверки результатов тестов.

## Результаты

После моделирования пользовательского тестирования было выявлено, что нововведение негативно влияет на удержание пользователей. С продуктовой точки зрения, результаты тестирования демонстрируют,
что boss level на 40-м уровне не улучшает вовлеченность и снижает
удержание пользователей на седьмой день.
